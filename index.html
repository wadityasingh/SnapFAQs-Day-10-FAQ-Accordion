HTML (HyperText Markup Language) is the standard foundation of every webpage on the internet. It defines the structure and meaning of web content using semantic elements such as headings (<h1>–<h6>), paragraphs (<p>), links (<a>), buttons (<button>), and landmark sections (<header>, <main>, <footer>). Think of HTML as the architectural blueprint of a website.

CSS (Cascading Style Sheets) is the styling language used to control how HTML elements look on screen. CSS handles colors, typography, spacing, borders, shadows, animations, and page layouts using modern tools like Flexbox and CSS Grid. Without CSS, websites would look like plain unformatted text documents.

JavaScript (JS) is the programming language of the web that makes websites interactive and dynamic. While HTML provides structure and CSS provides style, JavaScript lets you respond to user clicks, validate forms, fetch live data, update the Document Object Model (DOM), and power interactive components like this FAQ accordion.

Responsive web design is an approach to building websites that automatically adapt to any screen size—from 320px mobile phones and tablets to laptops and wide desktop monitors. It uses flexible grids, fluid images, relative typography (such as rem and clamp()), and CSS media queries (@media) so users never have to zoom or scroll horizontally.

An accordion is a vertically stacked list of interactive headers that users can click or tap to reveal or hide associated content panels. In an FAQ section, accordions keep the page clean and scannable by showing only the questions upfront, letting visitors expand the specific answers they care about without overwhelming the screen.

element.classList.toggle('active') is a built-in JavaScript DOM method that checks if an HTML element currently has a specific CSS class. If the class is missing, it adds it; if the class is already present, it removes it. You can also pass a boolean second argument—element.classList.toggle('active', shouldBeOpen)—to explicitly add or remove the class based on a condition.

Using a semantic <button> element instead of a generic <div> or <span> gives you built-in accessibility for free. Native buttons are automatically focusable with the Tab key, can be activated using both Enter and Spacebar, and clearly announce their role and state (via aria-expanded) to screen readers.

Event handling is how JavaScript listens for and responds to user actions—such as mouse clicks, keyboard presses, touch taps, or form submissions. By attaching an event listener like button.addEventListener('click', handleToggle), your code executes a specific function whenever that interaction occurs.

GitHub is a cloud-based platform built around Git version control. It allows developers to store code in repositories, track every change over time, collaborate with teammates via pull requests, showcase portfolio projects, and deploy static websites directly to the web.

To deploy with GitHub Pages: push your index.html, style.css, script.js, and README.md files to a public GitHub repository. Open your repository's Settings → Pages tab, select Deploy from a branch under Build and deployment, choose the main branch and / (root) folder, and click Save. Within a minute, your live website URL will be ready to share.

Browsers parse HTML into the DOM (Document Object Model), parse CSS into the CSSOM, combine them into a render tree, and execute JavaScript to handle dynamic updates. Regular website maintenance ensures links remain valid, content stays accurate, accessibility standards are met, and layouts work smoothly across new browser versions and mobile devices.

The most effective way to master frontend development is by building focused, real-world components—like navigation bars, responsive grids, modals, and FAQ accordions—using pure HTML, CSS, and vanilla JavaScript before jumping into frameworks. Inspecting your code with browser DevTools, testing keyboard navigation, and publishing projects on GitHub builds strong fundamentals.

PROJECT OVERVIEW · DAY 10 TASK

About SnapFAQs

SnapFAQs is a simple FAQ accordion project developed to practise HTML, CSS, and JavaScript. It demonstrates how interactive website components can make information easier to explore.

01. Single-open accordion logic powered by classList.toggle()
02. Accessible semantic buttons with aria-expanded & aria-controls
03. Zero external libraries — ready for direct GitHub Pages deployment

CORE TECHNOLOGIES

What This Project Demonstrates

Built from scratch using the three foundational pillars of modern frontend web development.

01. MARKUP

HTML5

Structure and semantic elements. Uses accessible landmark regions, structured headings, native <button> triggers, and WAI-ARIA attributes (aria-expanded and aria-controls) linking every question to its unique answer panel ID.

02. STYLING

CSS3

Styling and responsive layouts. Combines CSS custom properties (variables), CSS Grid, Flexbox, smooth expand/collapse transitions, and responsive media queries from 320px mobile screens up to wide desktop monitors.

03. INTERACTION

JavaScript

Events, DOM manipulation, and accordion interactions. Implements single-open accordion state management with classList.toggle(), dynamic plus/minus icon updates, keyboard arrow navigation, and live topic filtering.
